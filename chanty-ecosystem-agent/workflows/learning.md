# Workflow: Learning

Weekly:
1. `python3 -m eco report weekly`
2. Read the operational counts as diagnostics. Read the business block as the
   scoreboard.
3. Note anything with fewer than 8 sends as "still testing".

Monthly:
1. `python3 -m eco report monthly`
2. Characterize every win into an archetype. Fill in `reason_for_yes`.
3. Generate lookalike briefs and hand them to discovery.
4. Update the value model: replace assumed rates with observed ones where the
   sample supports it, and say which is which.
5. Write recommendations. Targeting, scoring, offers, sequencing, research depth,
   lookalike criteria only.
6. Anything touching pricing, suppression, compliance, approved claims or
   commercial terms goes to a human as a note, not as a change.

The loop: WIN, CHARACTERIZE, FIND LOOKALIKES, TEST, WIN, REFINE.
