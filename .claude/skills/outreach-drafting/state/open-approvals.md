# Open approvals

Austin is normally in the conversation when this agent runs, so most approvals are answered
on the spot and never reach this file. Anything still unresolved when a run ends gets filed
here so the next run does not re-raise it or quietly proceed without it.

Three kinds, per `.claude/gtm/crm-sync.md` and `.claude/gtm/sourcing-and-credits.md`:

- **Uncertain match**: both record links and what makes them ambiguous
- **Credit batch**: which targets, what is missing, which provider, estimated cost, balance
- **Candidate stage change**: the stage, and the quote or event that prompted it

Clear an entry when it is resolved. Say which run resolved it.
